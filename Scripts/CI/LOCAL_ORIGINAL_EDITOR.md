# Dedicated-Mac SDK intake

The complete schema3 shared-runtime route also accepts an explicit
`producer_kind: local-mac`. Its run identifier is the producer's real local UUID;
there are no fabricated GitHub run, job or artifact identifiers.

After the exact native import, original mobile ABI, complete SDK consumer and
shared implementation ownership gates pass, run
`prepare-local-original-editor-input.py` in the isolated Host checkout. Supply
the actual producer root, SDK evidence root, qualified ABI receipt and a fresh
`build/` destination. It preserves the signed distribution bytes and produces a
hashed ZIP plus `admission-candidate.json` and the original source/ABI sidecars.

Commit the reviewed candidate's exact bytes to the normal
`Scripts/CI/runtime27-original-editor.inputs.json` before using the original
restore and app-build commands. The existing source composition binding must
also be extended to the exact current application and dependency leaf. A local
artifact does not waive source composition. Historical SDK pins and their
unqualified state remain historical evidence until the new qualified pins exist.

The local variant uses the same complete API86 proof, real English/Hebrew
consumer observations, export inventory, architecture/signature checks, Clang
declarations, package/source equality and single implementation ownership gates.
StageB must still execute the saved annotation, mixed native blocks, save,
export/import and close/reopen journey with an actual new process ID.

`test_original_editor_local_admission.py` tests synthetic transport metadata
only. No test fixture in that file is runtime evidence. Simulator SDK intake
also grants no device framework, Release, TestFlight or physical-iPad acceptance.
