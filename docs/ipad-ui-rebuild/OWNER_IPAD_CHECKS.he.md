# בדיקת האייפד לאחר קבלת הבנייה הניסיונית

מצב המסמך: תוכנית בדיקה מוכנה. בניית TestFlight החדשה עדיין לא נשלחה; אין לראות במסמך אישור קבלה או הודעת מסירה.

הבנייה אמורה לשמר את ממשק 9401, ולהוסיף רק את סרגל חיפוש הספרייה, פס הספרים הפתוחים, סרגל הצד בעל שני העמודים, פרופילים וקבוצות, ותיקוני ה־Inspector ומראה המקום שסוכמו. אין צורך למחוק את האפליקציה או את הנתונים כדי לבדוק.

1. פתח ספר אמיתי מהספרייה. בדוק שהגופן, הניקוד, ההדגשות, צבע הרקע והסרגל התחתון נשמרו. פתח מידע על הספר, חיפוש בתוך הספר ואפשרויות תצוגה דרך הפעולות המקוריות.
2. הקש בשדה החיפוש המרכזי. בדוק שהחיפוש מתרחב, שהמקלדת מוצגת ושאפשר להקליד בעברית ובאנגלית. פתח ספר מתוצאה אמיתית ובדוק שהחיפוש מתקפל למקומו. בדוק גם מקלדת חיצונית, Escape ועכבר/משטח עקיבה אם זמינים.
3. הצג את סרגל הצד. עבור בין ספרייה לתוכן עניינים בעזרת שתי הנקודות ובעזרת החלקה. גלול והרחב ענף בספרייה, ועבור הלוך ושוב: הקורא ומצב העץ צריכים להישמר. בדוק גם את העמוד/הפרק המסומן בתוכן העניינים.
4. פתח כמה ספרים, החלף ביניהם, סדר אותם וסגור אותם עד קבוצה ריקה. פתיחת ספר חדש נעשית מהספרייה. אסור שיופיע עמוד דפדפן ריק או שפעולת סגירה תגרום לקריסה.
5. פתח את מסך כל הכרטיסיות. צור קבוצה ריקה וקבוצה מהכרטיסיות הנוכחיות; שנה שם, העתק והעבר כרטיסייה בין קבוצות. בדוק שהקבוצה הנבחרת והחברות בה תואמות לפעולה. מחיקה צריכה להציג אישור מתאים.
6. צור שלושה פרופילים ושלוש קבוצות בכל אחד. פתח את אותו ספר בשתי קבוצות במקומות שונים, החלף ביניהן וודא שלכל אחת נשמר מקום משלה. סגור את האפליקציה ופתח שוב; בדוק גם פתיחה חוזרת כשנבחרה קבוצה ריקה. הערות וסימניות קיימות צריכות להישמר.
7. עבור מהקורא לחיפוש הכללי, למחברים ולהיסטוריה וחזור, מספר פעמים. בדוק שהספר והסרגל התחתון נשארים זמינים. שאילתת היסטוריה מהחיפוש הכללי צריכה להישאר שם ולא להופיע כהצעה בחיפוש בתוך ספר.
8. פתח את כלי הלימוד באותה דרך כמו ב־9401. בדוק את הקטע הנבחר, המפרשים, הקישורים וההערות ואת שינוי רוחב הפאנל. הכותרות המיותרות והמסגרת החיצונית שהוסרו אינן אמורות להסיר פעולה או תוכן.
9. בספר אוצריא, בדוק שמראה המקום מציג יחידת ניווט אמיתית, כגון פרק או דף; סימון עמוד ב׳ צריך לשמור על הנקודתיים. הזז את מחוון הניווט ובדוק התאמה לתוכן בלי קפיצה בלתי צפויה.
10. סובב את האייפד, שנה את גודל החלון ועבור בין חלון רחב וצר. חזור על פתיחת חיפוש, סרגל צד וכלי לימוד. בדוק שאין חיתוך של כפתורים, פס ריק למעלה או היעלמות של הסרגל התחתון.
11. בדוק את ערכות הצבע המקוריות, גודל הטקסט הגדול ביותר, הפחתת תנועה ו־VoiceOver על המכשיר. בדוק שמות מובנים, סדר מיקוד, הקראת שדה החיפוש ותוצאותיו, ובחירת קבוצה. בדיקות סימולטור אינן מחליפות בדיקה זו.

בדיווח על תקלה כדאי לצרף מספר בנייה, דגם וגרסת iPadOS, שם הספר, רצף הפעולות, הצפוי מול מה שקרה וצילום מסך. אין צורך לצרף מסדי נתונים, חשבונות או מידע אישי.
