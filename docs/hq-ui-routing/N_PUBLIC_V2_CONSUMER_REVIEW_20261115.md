# N consumer review of P public-navigation v2

Reviewed immutable P packet `9835982a8bb629965c925337d4dcb94c941f678b`, including its contract, DTO/codec/registry/binding implementation and new tests. This review does not merge that packet, enable a v2 handler, opt any app descriptor into v2, modify the frozen native candidate, or claim native acceptance. Frozen checkout `13e40d1daa4a53799c94cd8ed5170f1343b9b1e8` and its manager-owned run remain independent.

## Required local-binding decision before N consumes v2

`bindPublicV2` constructs a complete private `RouteSpec`, including `state: .init(inspectorVisible: ...)`, but has no trusted local workspace/profile binding input. Its UI-only result is already an immutable `UIAuthorizedSceneCommand`. The current concrete N host requires the route's workspace/profile to equal the actual scene's `StudyWorkspaceNavigationAdapter.selection` and includes those actual IDs in `MaktabahNativeSceneProjection.surface`. `NativeSurfaceState.observedRoute` preserves that independently observed state. `UISceneReceipt.validate` then requires exact complete-route equality.

Consequently a root History surface bound by the current v2 implementation has nil workspace/profile, whereas the actual mounted workspace produces non-nil IDs. The existing driver rejects it before mutation; bypassing that check still cannot produce a matching completion receipt. N cannot add these local fields to the immutable authorized command after binding. Dropping the observed fields or echoing the requested empty state would violate the existing witness contract.

Resolve this local mapping before consumer activation. A suitable seam would accept narrowly typed **trusted host-local bindings** before creation of the immutable command/grant and bind them to the same exact scene revision/lifetime. These must never be added to `PublicNavigationSpecV2`, accepted from URL bytes, logged as public content or interpreted as permission. Reader plans must use the same agreed local-state mapping before obtaining their actual Core reader grant. This is a consumer compatibility issue in the future contract, not a failure of the frozen v1 packet.

`NPublicV2ConsumerReviewTests.swift` is a portable synthetic reproduction using P's actual v2 binder/Core and existing test authority, then the exact state shape produced by N's current History projection. It checks that canonical preparation can be issued, but the independently projected workspace/profile receipt is rejected with `scene_receipt_mismatch`. It is not a UIKit test and does not claim the current app has any v2 registration. Exact execution result and hashes are recorded separately in `N-public-v2-consumer-review.json`.

## N integration obligations after the shared contract decision

* Retain the exact `.surface` preparation through commit/completion. The current N orchestrator accepts an unprepared `UISceneCommand` and obtains preparation itself; a future prepared-plan entry must consume the already-issued one-use wrapper, with the same finite admission, driver identity checks, native observer cleanup and final live UIKit observation. Discarding the wrapper and re-preparing would lose the original binding's revocation boundary.
* Admit the exact trusted context **before** invoking the v2 binder and keep that same context/lifetime through the whole surface completion or the entire canonical Core reader result. Do not re-admit a replacement context between binding and committing. The existing v1 entry and its guards stay unchanged.
* A reader plan is structural. Keep the original local import invocation/deadline outside that plan; use its fresh UUID for the canonical `reader.open` request, carry only the remaining budget, and retain the original outer cooperative deadline scope. The actual sink uses Core's independently delivered invocation/deadline and grant. A raw `UIValidatedRoute` carries no original deadline.
* A future `newTab` implementation needs a bounded, scene-owned reservation that is not yet a visible/persisted tab. Do not mutate the existing tab/workspace model before the canonical final commit guard just to manufacture `localTabID`; release unused reservations on every failure/cancellation/lifetime change.
* Keep `/action/v1/` and the existing v1 codec frozen. A future explicitly versioned v2 envelope needs its own typed decoded case, exact path/wire-version consistency and the sole v2 byte codec. No parser fallback, implicit v1 promotion, unknown-component guess, backend substitution or HTTPS entitlement is introduced by this contract review.
* Only install exact native variants after their real component/presentation and content-rights checks exist. Current History-v1 and Settings-intent registrations do not prove Settings control focus, reader inspector/content, or any v2 support. The public DTO and registry opt-in never grant content rights, publication rights or persistent mutations.

The opt-in separation, absence of wire request/scene/tab/workspace/profile IDs, exact presentation/component allowlist, explicit migration, same-Core semantic reader path and retained completion validation fit N's intended boundary. Native focus/control before/after state, Shortcuts/system Intent behavior, all content variants and public publishing remain open acceptance work.
