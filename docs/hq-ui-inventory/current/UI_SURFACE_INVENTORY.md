# Current UI01 source inventory

The canonical machine-readable inventory is `UI01_CURRENT_HANDOFF.json`, generated by `reconcile.py --source <full SHA>`. Its source SHA, line anchors, Git blobs and SHA256 values identify the actual app graph. `RECONCILIATION_REPORT.json` records moved anchors, new files and the verified source census. Regenerate after a UI/source change; do not reinterpret an older producer branch as current truth.

Phase1 preserves227 original semantic rows and the real palette Cancel row, then inventories54 actual native Search controls/states. The Search field moved to NativeGlobalSearchField; Inspector provider identity now follows the actual section backend. Source inventory and implemented controls are distinct from public routing/native acceptance.

Current installed native variants are History/currentTab and Settings/sheet. Inventory IDs do not register routes. Search/Reader/TOC/Inspector are the original user surfaces; broader typed focus/scroll/newTab/public-v2 variants remain unavailable until their real native owner/sink/receipt acceptance. Five Core action implementations are derived from the actual ActionRegistry, not the29 metadata-only catalog descriptors.

Examples for real acceptance: open a versioned History URL and require its visible native surface plus one matching scene/backend/revision receipt; use the real Search tab to enter/clear a query and open the scrollable native options Form; switch Library/TOC in both directions while preserving the reader object/source/offset. Exact executed results belong to the Phase1 acceptance matrix and xcresult, never to an anchor census.

System Siri/Shortcuts, Hanlin live UI consumption, multiwindow/full-data/device behavior and unexecuted controls stay explicitly unaccepted. The sole current developer performs source/QA work; no independent agent review is claimed.
