The closed authority value is the internal `OriginalActiveSpaceSelection`: its constructor is fileprivate and retains the original selection attempt, account capture, Space view and generation. `currentOriginalActiveSpaceSelection()` is also internal. Exporting caller-supplied identity strings would not expose that authority.

Original import/reopen and process-resume setup are currently `OriginalEditorQualification` SPI guarded by `DEBUG && targetEnvironment(simulator)`. The public snapshot initializer decodes an existing payload; it is not an import operation. The production host still needs an original, closed route for native account/Space acquisition and persisted object import/reopen, with source retirement and real permission/lifetime checks preserved.
