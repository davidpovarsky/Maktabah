## What makes a runtime pass valid

1. Original retained v40 install receipt, official release identity, full actual database digest/counts/schema and installation manifest are admitted. The full source catalog is generated by the actual original Apple source closure.
2. The exact native case performs 100 real group changes between distinct document owners in one profile/namespace. It independently checks native selected group/card geometry and original persistent membership, locators and search state.
3. Each original UI action is bracketed by two host observations. The host resolves the exact installed app executable and actual PID, then reads Darwin `ps` RSS. Acknowledgements contain measured values only.
4. Every end observation must match exactly one original `NativeGroupSwitchPerformance` app record by namespace, scene, group/document identities, PID and revision interval. All 100 original operation UUIDs are unique, sequences contiguous, and launch identity identical.
5. The original app's elapsed time and `phys_footprint_bytes` remain separate from host RSS. Automation waits and observer round trips are not reported as app operation latency. No continuous peak, physical-device result or performance SLA is inferred.
6. The genuine xcresult attachment manifest must identify one cold-proof JSON attachment from the exact selected case and owned device. Its pre-cold PID must equal the 100-operation cohort; a fresh original source-observer request after terminate/relaunch must report a different PID. Namespace, profile, group, document, canonical locator, corpus, catalog and manifest remain bound. Cold scene identity may legitimately change.
7. Exact zero-skip native execution, complete 200 acknowledgements, unchanged source/app/test/SDK images, full post-UI database hash and retained Simulator shutdown are mandatory. A missing/partial observation or cleanup failure produces `FAILED_OR_INCOMPLETE`.

The original source observer supplies a complete source length and a bounded visible native source sample. This is not a hash of every rendered character. The Swift case verifies the pinned corpus receipt and actual manifest/size/SQL/source; the host performs the independent complete database hashes.

## Independent review corrections

The first review identified a genuine container-lifetime error: XCTest can relocate app data before launch. The final host discovers only its unpredictable request token under the same device's Application parent, asks `simctl` for the actual container and checks the original bundle metadata and installation manifest. It binds before the first transition and rejects a change during the 100-operation cohort.

The second correction requires actual cold process proof instead of relying on `terminate()`/`launch()` calls alone. The parser follows the existing exported attachment schema: a list of test records, `suggestedHumanReadableName`, `exportedFileName` and `deviceId`; it rejects wrong case/device, duplicate attachments, path escapes and symbolic links.

Sampling calls are explicitly bounded and stopping interrupts pending metric polling. The controller does not shut down a Simulator while its observer remains active. Xcode's distinct default and maximum time allowances are both set for this additional case.
